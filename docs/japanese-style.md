# 日本語の解説の書き方

Bash Explainer の日本語の解説（辞書や解説の文言）をそろえるための決まりです。英語の文言と対で書き、意味を一致させてください。[`test/ja-style.test.ts`](../test/ja-style.test.ts) が、下の「使わない表記」や、コードの前後の空白の抜けを見つけると失敗します。

## 文体

- **常体（だ・である調）で、文末は動詞の終止形か体言止め**にします。「〜する」「〜を表示」のどちらでも構いませんが、1つの項目の中ではそろえます。
- オプションの説明は、そのオプションを付けたときに**何が起きるか**を書きます（例: 「隠しファイルも表示」）。
- 注意が必要な操作は、末尾に「（注意）」を付けます（例: 「強制的に上書き（注意）」）。

## 用語

| 使う | 使わない | 補足 |
| --- | --- | --- |
| 作る | 作成する | 「作成時」のような名詞の形は可 |
| 削除する | 消す | |
| ヘッダー、ユーザー、サーバー | ヘッダ、ユーザ、サーバ | 長音を付ける |
| パラメータ | パラメーター | bash の用語（パラメータ展開、位置パラメータ）に合わせる |
| 表示する | | 人が読むために見せるとき |
| 出力する | | 標準出力やファイルに書くとき（パイプの先で使う値） |
| 標準出力、標準エラー出力 | stdout、stderr | 初出では「標準出力(fd 1)」のように fd 番号を添える |

## 記号

- 文の補足には**全角のカッコ**（）を使います。
- 略語や記号の注記は、**空白を入れずに半角のカッコ**で添えます（例: 「拡張正規表現(ERE)」「標準エラー出力(fd 2)」「より小さい(<)」）。
- コード、コマンド、オプション、値は `` ` `` で囲みます。日本語の「」はコードには使いません。
- `` ` `` で囲んだコードと、かなや漢字の間には半角空白を入れます（例: 「`local` は」「代わりに `[ ]` を使う」）。かなや漢字どうしの間には入れません（「代わりに一時ファイルを使う」）。「・」「、」などの記号との間には入れません（「`if`・`while`」）。
- 文の区切りの読点は「、」、項目の並びは「・」を使います。
